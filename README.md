# MagicMarkets logos

Official MagicMarkets logo files for partners, press and anyone who shows MagicMarkets prices.

![MagicMarkets logos](preview.png)

## Download

- **All files:** [MagicMarkets_Logos.zip](https://github.com/magic-markets/brand/releases/latest/download/MagicMarkets_Logos.zip)
- **One file:** open the [`logos`](logos) folder and download the file you need.

## Which logo to use

| Folder | Mark | Use it for |
| --- | --- | --- |
| [`02_Secondary-Horizontal`](logos/02_Secondary-Horizontal) | Ears + MagicMarkets | Column headers and source lines, for example "Prices from MagicMarkets". Use this one when there is room. |
| [`04_Monogram-Horizontal`](logos/04_Monogram-Horizontal) | Ears + MM | Small spaces where the full name does not fit. |
| [`06_Ears-Symbol`](logos/06_Ears-Symbol) | The ears | A small marker in a row or a table cell. |
| [`07_Square-Icon`](logos/07_Square-Icon) | The ears on a square | Lists or tables that show one square icon for each source. 32px to 256px. |

## Colours

| File suffix | Colour | Use on |
| --- | --- | --- |
| `CarrotOrange` | `#FF5408` | Light or dark backgrounds |
| `SnowBunny` | `#F2EBE8` | Dark backgrounds, or Carrot Orange |
| `EasterBrown` | `#0A0805` | White or light backgrounds |

## Formats

- **SVG:** vector. This is the best format for websites and apps.
- **PNG:** transparent background, 1000px wide. Square icons are opaque, at 32, 64, 128 and 256px.
- Clear space is built into each file. If you crop a file, keep clear space on all sides. The clear space must be equal to the height of the wordmark.
- Show the secondary lockup at 16px tall or more on screen.

## Rules

- Use the files as supplied. Do not redraw, stretch, rotate or rearrange the logo.
- The logo is always one solid colour. Do not add outlines, shadows, gradients or other effects.
- Put the logo only on a background with enough contrast.
- The name is always **MagicMarkets**: one word, with a capital M twice.
